# BYD CarPlay

寒叙（[@Hanxu4131](https://github.com/Hanxu4131)）基于 [DiPlay](https://github.com/shihabal3amri/DiPlay) 做的个人二次开发版，主要适配2023款唐 DM-i冠军版、21平台／控制器。保留原项目、xcertplay、DiAuto及已有贡献者的署名和许可证。

当前完整源码为 **v1.0.13 / versionCode 105**。v1.0.0保留为第64版的历史基线，后续修复和功能在此基础上迭代。v1.0.13已完成本地测试、编译及覆盖安装，新增普通CarPlay加载封面的实车效果仍待确认；不把安装成功当作所有问题已解决。

## 主要功能

- 21平台独立仪表地图，保留原车车速与挡位；整体区域、关键信息和转弯提示支持调整、缩放、实时预览、保存和取消。
- 仪表窗口启动失败时静默重试，配合外部L1Mini恢复显示顺序和有限唤醒。L1Mini的APK和镜头数据不在本仓库。
- 嘟嘟桌面分屏／全屏，H.264下保持连接并重新排版；连接成功及已连接再次打开时直接进入CarPlay。
- 导航播报时滚轮只调整导航音量，未播报时调整媒体；保留自动恢复服务的逻辑。
- 跟随车机深浅主题；独立地图外观选项。部分第三方手机地图的外观刷新仍可能延迟。
- 原车中控／仪表歌曲栏同步、歌手显示选项；MediaSession持续向桌面提供媒体信息。
- 音乐氛围灯支持音量、节拍、BPM等模式，多颜色范围、亮度和变化速度；支持专辑封面主色，彩色优先，无彩色时再判断大面积白色／冷白，否则使用可选颜色范围。
- 麦克风降噪／回声消除独立开关、方向盘按键映射、控制页重启。
- 旧21平台电量及纯电续航读取，低于自设阈值时向地图提供充电站建议所需车辆状态。
- 两路硬件视频解码优先、积压和欠载恢复，以及独立仪表流结束与主会话清理隔离。
- 连接期间持有Android高性能／低延迟Wi-Fi锁，断开后释放；不改热点、SSID、密码、Direct或配对配置。
- 中控与仪表加载画面：普通CarPlay使用玻璃方块图标和暖色背景，Ultra保留原来的蓝紫动画。

## 构建

需要JDK25、Android SDK37、NDK28.2.13676358，使用仓库内Gradle wrapper：

```sh
./gradlew :shared:testDebugUnitTest :common:testDebugUnitTest :mobile:lintDebug :mobile:assembleDebug
```

调试包名为 `com.shihab.diplay.tang21test`，应用名称为BYD Carplay，版本代码105。源码／CI构建不包含独立CarPlay连接所需的认证身份；本机独立构建需要用 `DIPLAY_AUTH_ASSETS_DIR` 显式提供外部运行时资产，更新既有安装还需要相同的Android签名。认证文件、签名密钥和密码不提交进Git。

## 验证与边界

v1.0.13本地完整测试为common407项、shared805项，共1212项，全部通过；lint零错误、22项既有警告。普通封面已检查仪表、分屏和全屏输出，Ultra在三个尺寸、三个动画时刻共9组逐像素比较与v1.0.12一致。公开同步的应用源码与测试保持一致，构建缓存和本机认证输入不上传。

此前在2023款唐DM-i／21平台实车确认过导航滚轮隔离、车机主题跟随、分屏与外部L1仪表显示、歌曲同步、音乐氛围灯及电量读取。这些功能仍可能有需要继续排查的间歇问题，不代表其他车型、所有固件或HEVC均通过。智能守卫历史0秒、原车360高负载、偶发自断联和分屏异常不宣称已全部修复。

真实CarPlay Ultra仪表主题及整车控制尚未实现，加载页中的Ultra标识只决定等待画面。内部摄像头集成保持停用，继续使用外部L1Mini。
