# 第26版：歌曲画面延迟取证

基于第25版。仅增加本机视频链的分段计时，不宣称修复歌词延迟。不改网络设置、连接握手、视频队列阈值、媒体缓冲、音量策略或已有界面。

每5秒记录一次：
- queueAge：视频收到后至交给解码器。
- codecOutputAge：交给解码器至产生输出。
- recvToRelease：视频收到至输出释放给 Surface。
- codecPresentAge：交给解码器至平台实际呈现回调。
- recvToPresent：视频收到至平台实际呈现回调。

每项含 avg/max/n。保留旧 shown 字段并标明 shownStage=released；presented 才是平台真实呈现回调计数。厂商没有回调时呈现 n=0、年龄=-1，不把释放输出当实际显示。计时不包含 iPhone 生成画面前及视频包到达解码入口前的延迟。

换 Surface、重建解码器时丢弃旧回调匹配，最多保留256帧。镜像启动画面最短1.5秒、最长5秒和现有两帧就绪回退保持。

实车核验应停稳后覆盖安装、重新连接，播放发生延迟的同一音乐应用。先观察有效呈现样本，再对照嘟嘟歌词、CarPlay画面与声音。不要仅按帧率相同就排除显示积压；只在确认延迟位置后修改播放策略。
