# 0.2.10候选源码迁移

本分支 `upstream-sync-0.2.10` 从已保存的test31源码开始，仅移植下面三组上游更新。它不是整包升级到0.2.10，也没有生成或安装新版APK。版本代码及安装ID暂未调整，等决定编译下一版时再统一处理。

| 已移植 | 行为 | 验证边界 |
| --- | --- | --- |
| 完整歌曲元数据与封面 | 标题、歌手、专辑、来源、时长、播放位置和封面；增量状态；有界解码队列与旧会话丢弃 | 保留原车歌曲栏开关、歌手选项、持续写入worker和桌面MediaSession；不据此保证歌词零延迟 |
| 通话AEC／NS和模式恢复 | 仅通话使用平台可用的回声消除、降噪及communication mode；失败继续录音，最后一路退出恢复 | 新增Android普通权限MODIFY_AUDIO_SETTINGS；实际车机效果需通话测试；Siri路径不改 |
| CAN／CANFD电池兼容 | 按协议选读取地址，未知能量省略，读失败清缓存，设置检查和后台轮询串行 | 旧21平台读数及手机端使用情况仍需实车确认 |

2026-10-03合并核验：shared 391项、common 241项，共632项单元测试通过；mobile debug lint为0 errors、18 warnings。这里的编译是测试和lint需要的源码编译，没有调用assemble或生成待安装APK。

未移植：Wi-Fi Direct、热点、端口选择、配对和网络启动路径；驻车视频播放器、无线诊断及其它与本次目标无关的改动。原网络设置和无线连接编排保持本分支基线。封面接收新增必要iAP2文件数据处理和回调，不改变网络配置。

待决定编译后停车测试：封面／播放进度是否被桌面正确读取，原车歌曲栏和歌手开关，通话回声／降噪及退出后音频模式，电池协议读数；同时复核原有21仪表、L1Mini、H.264分屏与外观跟随。
