# 摄像头接入记录（第49版，本地准备版）

第48版已验证的导航音量、氛围灯、CarPlay连接与比例适配保持原有实现。第49版新增摄像头设置和显示框架，摄像头总开关默认关闭。还没有完成独立取帧的实车验证，不能据此卸载或停掉L1Mini。

## 显示规则

- 左后、右后镜头常驻仪表两侧。
- 正后方在R挡或刹车深度达到40时显示；阈值可配置，刹车条件适用于所有挡位。
- 左前、右前只在D挡且CarPlay分屏时出现。进入全屏、离开CarPlay或数据失效时隐藏。
- 每侧由转向灯或对应方向的方向盘角度触发，两个条件都解除才关闭。默认角度15度，实际OEM信号单位和方向须实车核对。
- 左前和右前是独立窗口，后触发的在上层。清除上层条件后保留下层，不把两侧合成一个窗口。
- 中控窗口初始位置采用1920×1080参考区域：左22、上748、宽592、高242；位于后备箱按钮下面、底栏上面，保持长方形。其他分辨率按各轴比例换算，窗口位置和大小可单独调整。

## 分屏判断

按CarPlay实际宿主窗口和中控物理屏幕尺寸判断，容忍系统状态栏、菜单栏造成的少量差异。编码画布不是分屏依据：分屏时它可能仍然保持全屏尺寸。Activity暂停或被替代时清除旧状态，旧实例不能覆盖新实例的判断。

## 已接入的本地实现

- 五个镜头独立保存偏航、俯仰、滚转、视场角、平移、缩放、镜像及窗口位置/大小。
- 设置用草稿预览，取消恢复，保存才写入本应用私有配置。视角或窗口调整原地更新，避免为每次改参数重新打开摄像头。
- 参考配置只接受指定的摄像头字段，支持L1的11项CSV视角数据；不保留车辆序列号、手机号、热点或密码等未知字段。读取不改写L1原文件。
- NV12/NV21明确指定；GLES2进行显示与投影，不做CPU逐像素RGB转换。只保留最新待处理帧并复用有界缓冲区。
- 镜头校准不完整时不显示原始鱼眼画面。导入L1角度不等于还原了其未公开镜头模型。
- 每个来源由独立lease管理。正常隐藏不重开摄像头，保留显示资源和最新帧，触发时恢复显示；隐藏期间减少GPU绘制。过期来源和关闭后的回调不会继续显示；没有实时帧时隐藏窗口，避免冻结旧画面。
- OEM BMM采集适配器和独立app_process元数据探针已实现。主CarPlay进程没有自动调用JNI；探针必须由外部执行者设置进程硬超时。

## 下一次停车验证

1. 独立辅助进程检查OEM摄像头权限、回调布局、源通道、NV顺序与行步长；不扫描摄像头编号，不修改系统映射。
2. 确认原始源与五视角映射，核对镜头校准参数及方向盘、刹车、转向灯数据。
3. 验证仪表display 1与中控display 0的悬浮窗权限、实机GPU显示和窗口层级。
4. 验证与智能守卫录制共存、启动次序和重启；确认CPU、内存与帧率后才替代L1Mini。

设备参考库和用户视角配置只保留在工作区的私有研究目录，不打入APK，不上传仓库。当前不能认定摄像头接入已解决智能守卫0秒录制问题。
