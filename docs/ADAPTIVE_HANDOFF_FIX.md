# v1.0.14 分屏接管修复

后台会话接管会先设置主窗口尺寸，但手机端仍可能保留上一窗口的全屏区域。若接管时先出现未声明的临时尺寸，随后回到与 activeDisplaySize 相同的合法分屏尺寸，原有同尺寸早退会漏掉区域请求，留下全屏比例和上下黑边。

本次仅在 scheduleDisplaySize 与 applyDisplaySize 的同尺寸分支补充区域对齐。未声明尺寸仍跳过；目标已确认或本 Host 已选择该目标的当前 epoch 时不重复请求，不重新启动遮罩。既有 owner/epoch、最多三次请求及超时回退保持不变，不重连会话。

回归覆盖实际 adoptBackgroundSession 接管、旧全屏确认、1284×1080 临时尺寸返回 1284×990、确认后相同尺寸幂等、±2 像素抖动及最多三次请求。测试中的命令会话使用未连接 Socket，仅核验请求调度和状态；手机响应由 geometry/Texture 回调模拟。车内切换与真实协议写入仍需实车验收。
