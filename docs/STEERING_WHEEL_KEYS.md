# 方向盘按键

在“设置 → 方向盘按键 → 配置方向盘按键”中选择上一曲、下一曲、接听、挂断、Siri 或 CarPlay 主页，按一次实体按键，确认编号后保存。不按键也可以取消；取消不会改变已保存的映射。“清除映射”恢复该按键原来的处理方式，保存后不需要重新连接。

录入使用应用窗口、弹窗和 Android MediaSession 已收到的 KeyEvent，不使用 root 或无障碍服务抢占系统按键。车机 HOME、返回和音量按键保留系统行为；被系统或车辆控制服务拦截、没有交给本应用的按键无法录入。CarPlay 主页指 iPhone 的 CarPlay 主界面。若车机只发出媒体控制指令（例如直接调用“下一曲”），没有附带 KeyEvent，也无法识别实体按键编号；录入时会暂停执行这类指令，取消后恢复。

配置保存 keyCode 和 scanCode；scanCode 为 0 时按 keyCode 兼容。不同 scanCode 可以区分相同 keyCode 的实体按键，但收到 scanCode 为 0 的事件且存在多个候选时不执行，避免触发错误动作。同一个有效按键不能同时配置到两个动作。录入期间收到的按键只进入草稿，不执行原映射；同一次按下及其长按重复、重复分发只发送一次。

接听和挂断使用项目已有 Telephony HID descriptor：数组 index 1 是 Hook Switch（usage 0x20），index 3 是 Drop（usage 0x26）。CarPlay 主页使用已有 Knob HID 的 home 位。实现只发送对应 HID 按下及释放，不自行拨号。接听、挂断及车机实际按键分发仍需实车来电验证。

本地测试覆盖草稿取消、保存、清除、冲突、扫描码兼容、单次按下去重，以及媒体事件录入时不发送原媒体动作。测试不能代替车机系统按键分发和电话行为验收。
