# BYD Carplay 第47版：氛围灯与导航滚轮

本轮适配由 Hanxu4131 提出并用于自用唐2023／21平台版本。

氛围灯使用 CarPlay 媒体音轨 PCM 的能量和低频信息，不使用麦克风。方案包括随声音强弱、随节拍、估算BPM、鼓点优先、智能跟随。颜色支持原车编号1～31多选及全选；亮度上限0～6，0关闭控制并恢复接管前原车设置。最外层保存才应用，取消保留原配置。

舒缓、标准、快速只控制亮暗过渡，不改变节拍识别或换色拍数。亮起／回落的包络时间常数分别为120／450、45／220、0／70毫秒。硬件写入最多每秒5次，因此时间常数不代表原车灯70毫秒内完成过渡。三档仍使用同一颜色检测器，静音不会按固定秒数换色。

导航滚轮仅在实际导航播报、现有开关开启且无通话／Siri占用时拦截音量键，只写导航声道14；非播报期间交还系统。保留配对的按下／抬起，不写媒体声道。用户已实测播报期间只调导航、播报结束调音乐；后续覆盖安装要检查导航滚轮辅助服务仍启用。

隐藏比亚迪导航中的“HUD和仪表盘导航”开关，仅隐藏入口，不更改保存值和后台实现。

验证：共同模块306项、共享模块471项单元测试通过，无失败；Android lint无错误。车机SDK写入与原始灯光恢复已验证，实际歌曲中观察到多种颜色变化。第47版亮暗速度仍需用户在实体灯带上确认观感。网络设置与既有音频缓存配置保留。

L1Mini核心集成与智能守卫0秒问题还在独立分析，未并入本版本，未修改视角数据。
