# 第18版：启动画面和L1Mini覆盖顺序

基于test17/version45。保留苹果官网CarPlay Ultra PNG标识，改为蓝紫渐变光晕、玻璃质感背景、标识轻微入场和柔和扫光。使用Canvas绘制，不依赖视频文件或新网络资源；不是提取的官方开机动画，也没有接入Ultra主题。

首帧到达后220ms淡出，没有新增最短播放时长。8秒首帧回调超时移除覆盖的保护继续保留。

L1Mini的窗口恢复与故障恢复监控，从地图Surface建立时改为logo完全GONE之后开始。所有后续恢复检查窗口所有权、开关、display1、Surface仍存在、启动覆盖已结束；恢复命令发出前再检查一次。Surface销毁、启动画面再次出现、退出地图会取消旧任务，开关不能绕过等待。

这里只控制BYD Carplay发起的L1Mini恢复。L1Mini自己的开机启动或用户手动打开，仍由其自身处理，不能保证阻止它独立覆盖。

网络、协议、歌曲同步和深浅模式代码保持第17版；本地测试与实车效果分开记录。
