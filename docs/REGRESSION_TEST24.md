# 第24版：恢复方向盘按键入口

基于第23版，版本0.2.9-tang21-test24，versionCode52。

第23版把方向盘按键入口放进BydOutputSettings.available控制的比亚迪导航卡片。该条件验证部分原车导航输出接口；唐2023旧平台不满足条件，导致卡片连同按键入口隐藏。按键映射不依赖这些导航接口。

本版将方向盘按键移为应用设置上方的独立卡片，位于连接设置之后，按钮名“配置方向盘按键”。六项映射的录入、保存、取消、去重和持久化逻辑不变。网络、配对、启动画面及媒体数据路径均不改动。

从BYD Carplay应用的控制页面打开设置，点击“配置方向盘按键”。这是安卓应用自己的设置，不是iPhone投影里的设置，也不是车机系统设置。
