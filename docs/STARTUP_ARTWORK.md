# 启动画面

中控视频流开始后、首个画面实际呈现前，显示与仪表相同的 CarPlay 启动画面。第25版中控动态背景铺满应用当前窗口，兼容分屏和全屏，不再限制为16:9内容区域；图标仍按自身比例居中绘制，不拉伸。首帧到达后立即开始淡出，不额外等待仪表的最短展示时间。仪表仍保留 1.5 秒最短展示、5 秒兜底和 1.7 秒循环扫光。

“设置 → 显示与性能 → 启动画面”可以选择 CarPlay 或 CarPlay Ultra，中控与仪表共用。默认保留原来的 Ultra 画面；保存不重连，下一次等待首帧时使用新选择。已有视频画面时，普通恢复、分屏或尺寸变化不重新遮盖。断线重新连接时重新等待首帧，Activity 销毁时停止动画和超时回调。

这个设置只决定加载画面，不改变手机的 CarPlay 模式。现有协议中的 themeAssetsAvailable、clusterAsset 是能力或资源字段，仪表视频流也用于普通 CarPlay 地图，均不能可靠表示手机当前选择了普通 CarPlay 还是 Ultra。因此这一版没有将能力字段冒充当前模式，加载画面由用户手动选择。

1.0.13 的普通 CarPlay 封面改为暖灰、棕黑渐变背景，中央玻璃圆角方块内绘制白色 C 环和播放三角，下方保留白色 Apple CarPlay 字标，不包含手机状态栏。图标保持正方形，字标保持 400:98 比例，整体根据窗口宽高共同缩放并居中，兼容宽仪表、窄分屏和全屏。渐变与路径只在尺寸变化时创建，使用原生 Canvas 和现有矢量资源，无新增图片、视频或依赖。Ultra 继续使用原画面、尺寸和 1.7 秒循环动画；等待首帧与淡出逻辑保持不变。
