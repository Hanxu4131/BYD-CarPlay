BYD Carplay v1.0.0

把个人测试第64版作为后续开发的稳定基线，下一候选版本为v1.0.1。

这一版保留此前的唐21平台适配，局部合入上游PR332的平台加密实现。网络配置没有改动。

此前在2023款唐DM-i、21平台确认过导航滚轮隔离、车机主题跟随、分屏和外部L1仪表显示、歌曲信息与音乐氛围灯。旧21平台电量读取也已确认：达到自己设置的低电量阈值后，地图提示寻找充电站。NS／AEC独立开关在第63版获得用户确认；旧版不兼容路径不作为这一版的兼容性保证。

私用第64版对应源码已完成本地构建，1017项测试通过。本次公开源码另行验证，common 344项、shared 672项，共1016项测试通过；公开源码保留中性加载图，相关图形测试与私用版有所区别。v1.0.0是稳定基线命名，没有新增第64版实车改善结论；平台加密改动是否改善车内表现，还需要实车确认。以上范围也不代表全车型支持。

本次公开源码与说明，不上传自用APK、认证身份、签名材料、车内日志或设备资料。公开源码保留中性加载图形。普通源码构建不含独立运行所需的本机认证身份。
