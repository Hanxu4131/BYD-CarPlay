## 深浅模式

- 旧版语言包装复制完整Configuration，会把页面创建时的uiMode和窗口尺寸固化。新版只覆盖语言和阅读方向，保留系统配置的后续更新。
- 实车只读检查发现UiModeManager的夜间选择被锁定，当前类型为普通模式。新版在锁定或锁定接口不可读的普通模式下优先读取实际资源配置，避免固定的MODE_NIGHT_NO压住车机的深色配置。
- 外观消息只有发送成功后才标记已应用；失败保持可重试，快速深浅往返和旧会话迟到回调不会覆盖最新状态。连接期间继续轮询，打开车机设置不会暂停同步。
- 不改网络、连接模式、协议外观命令。若厂商主题切换完全不更新Android配置，仍需实车日志定位其独立信号。
