# 第22版：方向盘按键映射

基于第21版，版本0.2.9-tang21-test22，versionCode50。保留第21版外观、仪表首帧和歌曲字段修复，网络与配对配置不变。

设置里的方向盘按键支持上一曲、下一曲、接听、挂断、Siri和CarPlay主页。选择动作后按一次方向盘按钮，显示编号及扫描码，再取消或保存。取消不会修改原配置；清除映射恢复默认。同一有效按钮不允许保存到多个动作。

录入和执行共用窗口、弹窗与媒体会话收到的按键。按住重复及同一次事件重复分发仅执行一次。录入期间不执行原动作，不申请额外音频焦点；设置保存后无需重连。不能录入系统没有交给应用的按键；只收到媒体控制指令、没有KeyEvent时也无法识别编号。

接听和挂断复用已有Telephony HID，分别是数组索引1和3；对应Hook Switch 0x20和Drop 0x26，已与USB-IF HID Usage Tables核对：https://www.usb.org/sites/default/files/hut1_21_0.pdf。主页复用Knob HID的home位。没有增加拨号或车辆控制命令，实际来电行为仍需实车验证。

智能守卫为独立的第三方应用，本版没有修改它的APK。诊断记录单独保存，未读取录像内容。

本地核验：APK编译成功；26项相关测试全部通过（方向盘映射6项、媒体回调3项、后台重启5项、后台会话UI恢复4项、歌曲字段2项、外观6项）。lint 0错误、18警告。代码定点核对：Controller只增加电话及主页事件发送入口，网络目录、配对持久化及其余连接编排未改动。实际实体按键录入和电话接听/挂断仍待车机测试。
